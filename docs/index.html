🚀 Sobre Este Projeto

O CT&I-PE é uma solução de Gestão do Conhecimento desenvolvida para centralizar e visualizar indicadores de ciência, tecnologia e inovação. O projeto utiliza tecnologias modernas como Streamlit, SPARQL e GitHub Pages para oferecer uma experiência integrada e acessível.
